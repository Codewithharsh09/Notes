# SQL

Premium, interview-focused SQL notes — built to take you from zero to backend-ready and interview-ready.

This course is organized as a set of modules, each covering one topic in full depth: concepts, internals, syntax, examples, common mistakes, best practices, interview questions, practice problems, cheat sheets, and flashcards.

## Modules

- **[#1 Introduction](./introduction)** — What SQL is, why it exists, databases & their types, SQL command categories, and setting up your environment.
- **[#2 Query Data (SELECT)](./query-data)** — SELECT, FROM, WHERE, ORDER BY, GROUP BY, HAVING, DISTINCT, TOP/LIMIT, and query execution order.

More modules will be added as the course progresses.
